# 003 – Manual catch-up logging

- **Date:** 2026-10-17
- **Status:** accepted

## Context

iOS doesn't let third-party apps read call history, SMS/iMessage, or other messaging apps.

## Decision

The user logs catch-ups manually. The default is a one-tap "caught up today".

## Consequences

- Reliable and simple, but it depends on me remembering to tap. The daily digest and a fast logging flow are there to make this easy.
